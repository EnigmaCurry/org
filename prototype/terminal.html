    Dependencies

    This site is built with:

    • Emacs
    • Org-mode
    • Ox-hugo
    • Hugo (extended edition)
    • GitHub actions (also compatible with Gitea actions)

    To build locally, you must install Emacs (29+), and hugo (v0.120+), using your package manager, or by downloading directly from their respective project pages. Please be aware that hugo has two editions: standard and extended, and this build requires the extended edition.

    note
    Your package manager may contain an old version of Hugo that is incompatible with the Relearn theme. Install the latest version of Hugo from the Hugo GitHub releases page.

    For example, to download the X86_64 release of hugo v0.123.8:

    [bash]: Run this on your workstation:
    HUGO_VERSION=0.123.8
cd ~/Downloads
wget https://github.com/gohugoio/hugo/releases/download/v${HUGO_VERSION}/hugo_extended_${HUGO_VERSION}_linux-amd64.tar.gz
tar xfvz hugo_extended_${HUGO_VERSION}_linux-amd64.tar.gz
sudo install hugo /usr/local/bin/hugo

    Building locally

    Change into the directory where you cloned the source, then run the install method to download the theme and build the site:

    [bash]: Run this on your workstation:
    cd ~/git/vendor/enigmacurry/org
make install   ## downloads/installs the theme
make build     ## builds the static site into public/
make serve     ## builds + runs the live-reload server

    Live-reload preview

    The make serve target rebuilds on every save and serves the site with live reload at http://localhost:1313, drafts enabled.

    Publishing with GitHub pages

    This site is automatically published to GitHub Pages via the included action file .github/workflows/deploy.yaml. Fork the repository, enable the action, and it publishes to your own site whenever you git push.

    Custom domain

    Set your domain in the CNAME file and point a DNS record at GitHub Pages; the included workflow republishes there on every push.
